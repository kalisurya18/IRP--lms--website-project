# IRP LMS Website and Web Development Foundations

This repository contains my Web Development Foundations practical assignment, covering responsive web design using HTML and CSS and JavaScript fundamentals.

## Part A: Responsive UI – IRP LMS

A responsive IRP Learning Management System website developed using HTML5 and CSS3.

### Files
- `index.html` – Home page with learning journey section.
- `courses.html` – Courses page with course videos.
- `contact.html` – Contact page with contact form.
- `style.css` – Styling and responsive layouts.

### Features
- Responsive navigation bar.
- Hero section with learning content.
- Learning journey cards.
- Course video section.
- Contact form.
- Responsive layouts for desktop, tablet, and mobile.

## Part B: JavaScript – Bank Simulator

A JavaScript program demonstrating data types, type coercion, scoping, hoisting, and asynchronous loops.

### File
- `bank.js` – JavaScript practical assignment.

### Concepts Covered
- Types and type coercion.
- Amount validation using `parseAmount()`.
- `var`, `let`, and `const`.
- Hoisting and Temporal Dead Zone (TDZ).
- Function declarations and function expressions.
- Asynchronous loops using `setTimeout()`.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js

## How to Run Part B

Run the following command in your terminal:

```bash
node part-b-javascript/bank.js
```

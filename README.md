# IRP – LMS Website and Web Development Foundations

A responsive Learning Management System website built as a web development practical project, alongside JavaScript fundamentals exercises.

## Live Demo

[Open IRP LMS Website](https://irp-lms-webiste.netlify.app/)

## Part A: Responsive UI – IRP LMS

A responsive educational website developed using HTML5 and CSS3.

### Features

- Responsive navigation bar.
- Hero section with learning content.
- Learning journey cards.
- Course video section.
- Contact form.
- Layouts designed for desktop, tablet, and mobile screens.

### Files

- `index.html` – home page.
- `courses.html` – courses page with course videos.
- `contact.html` – contact page and form.
- `style.css` – styling and responsive layouts.

## Part B: JavaScript – Bank Simulator

A JavaScript program demonstrating core language concepts.

### Concepts Covered

- Data types and type coercion.
- Amount validation using `parseAmount()`.
- `var`, `let`, and `const`.
- Hoisting and Temporal Dead Zone.
- Function declarations and expressions.
- Asynchronous execution using `setTimeout()`.

Run Part B using Node.js:

```bash
node part-b-javascript/bank.js
```

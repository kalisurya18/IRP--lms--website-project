# IRP LMS Website Recreation

A beginner-friendly, responsive recreation of the IRP LMS assignment using HTML5 and CSS3 only.

## Files
- `index.html` — Home page and five-step learning journey
- `courses.html` — Nine course video cards using the YouTube embed URLs in the assignment
- `contact.html` — Contact information and message form
- `style.css` — Shared colors, layout, and responsive styling

## Run locally
1. Download or extract this project.
2. Open the `irp-lms-website` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Use the navigation links to test all three pages.

## Notes
- The design uses the supplied Cloudinary image assets and the specified color palette.
- The contact form is front-end only; it does not send messages to a server.
- The Sign In button is a visual placeholder, as authentication is outside the assignment scope.
- YouTube videos require an internet connection.

## GitHub submission
Create a **public** repository on GitHub, upload all four files, and submit the public repository URL. Test the published files before submitting.
